# 🔍 نظام البحث والتحقق — سوريا

نظام مفتوح المصدر، مجاني بالكامل — بحث سريع بالاسم أو الرقم الوطني، مع مسح QR، توليد رموز QR، تصدير PDF، واستيراد وتصدير CSV. يعمل بالكامل محلياً بدون خادم.

## ✅ الميزات
- 🔍 بحث فوري: بالاسم الأول، الاسم الكامل، أو الرقم الوطني
- 📲 توليد رمز QR لكل سجل
- 📷 مسح رمز QR عبر كاميرا الجهاز
- 📄 تصدير النتائج إلى PDF بدقة عالية
- 📊 استيراد وتصدير ملفات CSV
- 📋 نسخ البيانات إلى الحافظة
- 📱 واجهة عربية متجاوبة — تعمل على الجوال والحاسوب
- 🌐 يعمل محلياً بالكامل — لا يحتاج خادم بعد التحميل

## 🚀 طريقة التشغيل
1. افتح `index.html` في المتصفح
2. اكتب الاسم أو الرقم في مربع البحث
3. اضغط بحث أو Enter
4. استخدم أزرار النسخ، QR، PDF حسب الحاجة
5. استورد بياناتك عبر زر "استيراد CSV" أو صدّر الكل

## 📂 هيكل الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة الرئيسية |
| `data.js` | قاعدة البيانات المحلية |
| `app.js` | منطق البحث والميزات |
| `styles.css` | التصميم والتنسيقات |
| `README.md` | دليل الاستخدام |

## 📝 إضافة بيانات
أضف السجلات في ملف `data.js` بنفس التنسيق، أو استورد من ملف CSV.

## ⚠️ ملاحظات
- البيانات مخزنة محلياً في المتصفح
- يُنصح بتصدير CSV دورياً كنسخة احتياطية
- هذا النظام مخصص للاستخدام التنظيمي الداخلي
- تأكد من دقة البيانات المُدخلة
