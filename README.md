# 🔍 نظام البحث والتحقق من البيانات الشخصية السورية

نظام مفتوح المصدر بسيط وسريع للبحث عن البيانات الشخصية بالاسم أو الرقم الوطني.

## ✅ الميزات
- 🔍 بحث فوري بالاسم الكامل أو الجزئي أو الرقم الوطني
- 📋 عرض جميع البيانات في بطاقة منظمة
- 📋 زر نسخ البيانات — 🖨️ زر طباعة
- 📱 يعمل على الجوال والحاسوب
- 🔌 يعمل بدون اتصال إنترنت
- 📂 قاعدة بيانات محلية يمكن توسيعها بسهولة

## 🚀 طريقة الاستخدام
1. افتح `index.html` في المتصفح
2. اكتب الاسم أو الرقم الوطني في مربع البحث
3. اضغط "بحث" أو اضغط Enter
4. تظهر جميع البيانات فوراً ✅

## 📂 هيكل البيانات
- الاسم الكامل — الرقم الوطني — رقم البطاقة — تاريخ الميلاد
- العنوان — الهاتف — الرقم الضريبي — الجنسية

## 📝 إضافة بيانات
افتح ملف `data.js` وأضف السجلات بنفس التنسيق الموجود.
