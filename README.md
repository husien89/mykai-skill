# 🔍 نظام البحث والتحقق من البيانات الشخصية السورية

نظام مفتوح المصدر، مجاني بالكامل — بحث سريع بالاسم أو الرقم الوطني، مع مسح QR، تصدير PDF، واستيراد وتصدير CSV.

---

## ✅ الميزات الرئيسية
- 🔍 بحث فوري: بالاسم الكامل أو الجزئي أو الرقم الوطني
- 📷 مسح رمز QR: افتح الكاميرا وامسح الكود لجلب البيانات فوراً
- 📄 تصدير PDF: احفظ أو أطبع النتائج كملف PDF بدقة عالية
- 📊 استيراد وتصدير CSV: انقل البيانات بين الأجهزة بسهولة
- 📋 عرض بيانات كامل: الاسم — الرقم الوطني — البطاقة — تاريخ الميلاد — العنوان — الهاتف — الرقم الضريبي
- 📋 نسخ سريع + طباعة مباشرة
- 📱 متجاوب بالكامل — يعمل بدون إنترنت
- 🌐 واجهة عربية كاملة

---

## 🚀 طريقة التشغيل
1. افتح `index.html` في المتصفح
2. ابحث بالاسم أو الرقم، أو اضغط أيقونة الكاميرا لمسح QR
3. صدّر النتائج PDF أو CSV من الأزرار في الأسفل
4. استورد بياناتك من ملف CSV بسهولة

---

## 📂 الملفات
| اسم الملف | الوظيفة |

---

## 📝 إضافة بيانات
افتح `data.js` وأضف السجلات بنفس التنسيق، أو استورد من ملف CSV.

- احفظ نسخة احتياطية من ملفاتك باستمرار
